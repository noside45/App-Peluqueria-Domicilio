# 💇‍♂️ App de Servicios de Peluquería a Domicilio

## 📋 Descripción del Proyecto
Plataforma digital diseñada para conectar clientes con profesionales de la peluquería, permitiendo reservas en tiempo real y servicios a domicilio de manera eficiente y segura. [cite: 14, 17]

## 🛠️ Configuración del Repositorio (GitFlow)
Para este proyecto utilizamos una estructura de ramas estricta para garantizar la estabilidad: [cite: 67]

* **main**: Código estable en producción. [cite: 68]
* **develop**: Rama de integración para desarrollo. 
* **feature/**: Ramas para nuevas funcionalidades (ej. `feature/login`). [cite: 70, 72]
* **fix/**: Ramas para corrección de errores (ej. `fix/calculo-tiempo`). [cite: 70, 75]

## 📝 Convención de Commits
Se deben utilizar mensajes descriptivos siguiendo este formato: [cite: 78]
* `feat:` para nuevas funciones. [cite: 79]
* `fix:` para arreglar errores. [cite: 80]
* `docs:` para cambios en la documentación. [cite: 81]
