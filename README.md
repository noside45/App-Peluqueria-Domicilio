# 💇‍♂️ App de Servicios de Peluquería a Domicilio

## 📋 Descripción del Proyecto
Plataforma digital diseñada para conectar clientes con profesionales de la peluquería, permitiendo reservas en tiempo real y servicios a domicilio de manera eficiente y segura.

## 🛠️ Configuración del Repositorio (GitFlow)
Para este proyecto utilizamos una estructura de ramas estricta para garantizar la estabilidad:

* **main**: Código estable en producción. 
* **develop**: Rama de integración para desarrollo. 
* **feature/**: Ramas para nuevas funcionalidades (ej. `feature/login`). 
* **fix/**: Ramas para corrección de errores (ej. `fix/calculo-tiempo`).

## 📝 Convención de Commits
Se deben utilizar mensajes descriptivos siguiendo este formato:
* `feat:` para nuevas funciones.
* `fix:` para arreglar errores.
* `docs:` para cambios en la documentación.
